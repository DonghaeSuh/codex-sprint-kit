# 합성 리허설 — 실제 평가 문제와 무관
문제를 고른 뒤 60분 타이머를 시작한다. 답안은 이 저장소에 제공하지 않는다.
0–8분 요구 파악, 8–30분 최소 동작, 30–45분 개선, 45–55분 검증,
55–60분 한계와 결정을 직접 설명한다. 외부 AI·도구는 실제 연습 환경의 허용 범위를 따른다.

## A. CSV 집계 (추천 첫 연습)
batch_id,good,total 열을 가진 UTF-8 CSV를 읽는 summarize.py를 만든다.
명령은 python3 summarize.py input.csv, stdout은 JSON, 실패는 stderr와 nonzero exit.
배치 중복은 합산한다. yield는 전체 good / 전체 total이다. 행별 비율의 평균이 아니다.
good/total은 정수, 0 <= good <= total, batch_id는 비어 있으면 안 된다.
빈 데이터, 누락 열, 음수, 소수, total=0인 행은 실패 처리한다.
정상 출력: {"batches":{"A":{"good":9,"total":10}},"yield":0.9}.
기본 검사: python3 practice/grade_csv.py --solution /path/to/summarize.py.
고정 검사는 채점 계약의 일부만 다룬다. 별도 경계 사례를 추가하되 개선 전후에 동일하게 실행한다.

## B. 웹/API
업무 요청의 제목 등록, 목록 조회, 완료 상태 변경 기능을 구현한다.
빈 제목 거부, 존재하지 않는 ID 처리, 재시작 후 데이터 보존을 명세에 포함한다.
API는 로컬 요청으로 검사하고 화면은 직접 조작한다.
완료 기준: 정상 등록→조회→완료, 빈 입력, 없는 ID, 재시작 후 복원.
필수 UI 상태: 비어 있음 / 성공 / 실패 / 재시도. 배포는 필요 없다.

## C. 기존 결함 수정
A의 정상 구현에서 연습자가 분모를 행 개수로 바꾸는 결함을 만든다.
수정자는 처음부터 구현을 다시 만들지 않고 실패 사례로 원인을 찾아 수정한다.
완료 기준: 재현이 수정 전 실패하고 수정 후 통과하며 다른 데이터 검사가 유지된다.
