# AI 없이 6문항 × 5분
제출 전까지만 함께 검토하고, 연습 답변은 본인이 직접 입력한다.
1. 핵심 사용자 흐름과 실제 확인 방법은?
2. 입력이 결과가 되기까지의 처리 경로는?
3. 가장 중요한 설계 선택과 버린 대안은?
4. AI 제안 중 그대로 쓰지 않은 내용과 이유는?
5. 재현한 실패와 수정 근거는?
6. 남은 한계와 추가 시간이 있을 때의 우선순위는?

각 답변: 문제 → 내 선택 → 실제 검증 근거 → 한계.
자기 점검 (공식 평가 기준 아님): 구체성·사실 일치·근거·한계 각 0–2점.
“테스트했다”보다 어떤 입력에서 어떤 결과를 확인했는지 쓴다.
