# 실무자 질문과 합의
실제 업무 채널의 답변만 기록한다. 모의과제 비밀 설정을 직접 읽어 채우지 않는다.

질문 순서: 최근 문제 사례 → 현재 처리 방법 → 성공 기준 → 예외/경계 → 우선순위 → 합의 확인.

| ID | 시각 | 질문 | 실제 답변·출처 | 요구사항 ID | 검사/구현 반영 | 미확인 사항 |
|---|---|---|---|---|---|---|

## 확인된 합의
- 해결할 문제:
- 필수 결과와 성공 기준:
- 하지 않을 일:
- 미확인 가정과 다음 질문:

답변을 기다리는 동안 가능한 독립 작업을 진행한다. 답변이 없다는 이유로 업무 규칙을 지어내지 않는다.
