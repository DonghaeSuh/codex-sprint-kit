# Session boundaries
실제 과제 README·운영 규정·사용자 지시가 이 기본 지침보다 우선한다.

- 실제 구현·실험·검증은 제공된 응시 작업 공간에서만 수행한다.
- 제공된 AI만 이용한다. 개인 키·외부 모델·새 인증 경로를 추가하지 않는다.
- 실제 문제·데이터·코드·로그를 공개 키트 안에 저장하지 않는다.
- .sprint는 과제 루트에 둔다. 키트 폴더의 .gitignore가 상위 .sprint를 보호하지는 않는다.
- 응시 중 Git push, 원격 PR/issue, 파일 업로드, 원격 배포, 외부 로그·추적 전송을 하지 않는다.
- 공개 자료 다운로드와 일반 문서 조회도 실제 허용 범위 안에서만 한다.
- Computer Use가 금지된 환경에서는 UI는 사용자가 직접 확인한다.
- 후속 평가에서 AI가 금지되면 모든 AI 요청·작업을 중단한다.
- 이 파일은 운영 지침이며 OS 수준 격리나 네트워크 차단 기능이 아니다.
